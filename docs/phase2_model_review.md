# 阶段 1 模型审查与阶段 2 修正

## 审查结论

阶段 1 的两阶段信息结构、预算分配主线和有限场景 C&CG 方向成立，可以继续实现。阶段 2 编码前对以下问题进行了澄清或修正。

## 1. 过期库存的双重计量

阶段 1 初稿使用 `w=I_oldest`，同时把 `I_oldest` 纳入期末库存容量。这会让同一批到期物资既作为浪费退出，又占用期末库存容量。

阶段 2 改为：

- 对非最后库龄：`available = consume + ending_inventory`；
- 对最后库龄：`available = consume + waste`；
- 最后库龄的期末库存固定为 0；
- 仓储容量只计算仍可结转的库存。

因此浪费和库存不再重复计量。

## 2. 仓储容量的计量时点

阶段 2 明确采用“当期消费和到期处置后的期末容量”。当前模型没有限制期初到货瞬间的临时仓储占用。该假设适用于到货后立即分拣和发放的业务场景；若案例要求所有到货必须先入库，应增加消费前容量约束。

## 3. 内生储备与固定储备的预算规则

- 确定性内生模型采用 `regular_cost + R = B`，未用于常规采购的资金全部成为可用储备，因此 `R/B` 可识别。
- 固定比例模型采用 `R = rho*B` 和 `regular_cost <= B-R`。常规采购额度未使用部分不能转入应急储备，体现固定预算科目的刚性。

两者规则不同是有意的政策设定，不是代码误差。后续实验如要进行“纯机制”对比，应额外报告常规额度闲置金额。

## 4. 预留资金与真实成本

`R` 是资金可用上限，不是已发生成本，因此不直接进入目标函数。目标函数计入：

- 已承诺的常规采购成本；
- 场景中的真实应急采购支出；
- 缺货惩罚；
- 过期浪费惩罚。

这避免把尚未使用的储备金误当成实际费用。

## 5. 确定性与固定储备模型的比较口径

`DeterministicModel` 只使用分量均值场景；`FixedReserveModel` 默认同时约束全部训练场景并最小化最坏场景成本。因此两类模型的目标值不能直接解释为固定比例的优劣，只能分别作为：

- 确定性规划基线；
- 固定比例下的鲁棒基线。

固定比例之间可以直接比较；确定性方案的鲁棒表现应在后续样本外评价中计算。

## 6. FIFO

连续 LP 和正浪费成本保证至少存在一个 FIFO 最优解，但求解器可能返回等价的非严格 FIFO 解。阶段 2 不引入二进制 FIFO 约束，也暂不运行第二级破平局目标。输出结果用于成本、缺货、浪费和预算验证，不将具体库龄消费顺序解释为唯一政策。

## 7. 信息结构

常规采购计划 `y[k,t]` 在所有场景揭示前确定；应急采购、消费、库存、缺货和浪费在完整场景揭示后调整。这是两阶段完全补救近似，不是逐期只观察历史信息的多阶段模型。论文中必须保持这一表述。

## 8. 阶段 2 暂未纳入的内容

- 常规采购供应上限；
- 采购或运输提前期；
- 消费前仓储容量；
- 严格 FIFO；
- 内生储备的全场景鲁棒模型；
- C&CG。

这些内容不影响阶段 2 最小模型运行，但应在后续阶段按研究优先级逐项加入。
