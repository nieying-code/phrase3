## 阶段 1 关键建模决策

- 内生模型采用“剩余预算进入应急储备”的等式分配，解决 `R` 非唯一问题。
- 固定比例模型的 `R` 固定，剩余常规采购额度只作为上限，反映刚性预算分区。
- 库存模型按库龄精确流转，过期量等于最老库龄期末剩余。
- 基础连续 LP 不引入 Big-M；在非负浪费成本下至少存在 FIFO 最优解，但尚未执行“优先消费老库存”的第二级词典序破平局，因此求解器返回值不保证严格 FIFO。
- 对库存容量造成的不可行补救，C&CG 加入完整不可行场景，不用任意可行性罚项。
- SPW-C&CG 复用有效场景但不裁剪完整 oracle，保证与冷启动和扩展式可核对。
