## 冻结主要估计量

主要估计量是 10 个独立种子三元组上的配对差：

> M2.1 验证集入选端点 − M2 最小端点的样本外 CVaR95。

逐种子差值为：

```text
-0.0709188355, -0.0323547804, -0.3164197279, -0.0150566122,
-0.3080344335, 0.0000000000, -0.0423678111, -0.0505083382,
 0.0000000000, -0.2703133004
```

复算结果：

- 配对均值：`-0.11059738391486462`；
- 配对中位数：`-0.04643807461980032`；
- 10,000 次种子三元组配对 bootstrap 95% 区间：`[-0.19313806539434156, -0.03810267027260127]`；
- Pratt Wilcoxon 双侧近似：统计量 `0`，`p=0.00764079482470999`；
- 冻结支持规则（均值小于 0 且 bootstrap 上界小于 0）通过。

但实际幅度极小：M2 与 M2.1 的平均 CVaR95 分别为 `42110.8156923823` 和 `42110.705094998375`，相对变化仅 `-0.00026263415252455275%`。因此结果只支持方向上的轻微改善，不能表述为具有明显实践意义的风险降低。

## 端点选择与描述性基准

- 10 个训练—验证三元组中，8 个选择最大端点，2 个选择最小端点。
- 两个选择最小端点的三元组中，M2 与 M2.1 引用同一方案制品并独立完成评价，主要差值严格为 0。
- M2.1 的平均成本和服务水平相对 M2 也仅有极小变化。
- 固定 30% 的描述性平均 CVaR95 为 `40347.19914411912`，低于 M2.1；固定 50% 的描述性平均成本和服务水平也优于 M2.1。

固定比例比较不是本批主要确认检验，不能据此重新选择端点、修改模型或宣称 M2.1 已解决原有策略差距。当前最稳妥的科学结论是：验证集端点选择在新测试集上呈一致但几乎可忽略的 CVaR95 改善，仍不足以形成强实践贡献。
