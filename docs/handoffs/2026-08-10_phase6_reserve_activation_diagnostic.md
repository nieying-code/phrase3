## 诊断结果

### 1. 不是粗网格漏掉小正储备

基线内生解为：

```text
objective = 18448.853760028822
R = 0
R/B = 0
```

最小正储备比例只有 0.25%，但目标已增加 `12.8813701445`；随后目标随储备比例严格增加，10% 储备时增加 `515.2548057802`。因此，`R=0` 不是因为 E2 只比较 10%/30%/50% 固定比例而漏掉很小的正储备区间。

### 2. 模型和求解器能够激活储备

| 应急价格缩放 | 储备比例 | 鲁棒目标 | 解释 |
|---:|---:|---:|---|
| 1.00 | 0 | 18448.853760 | 冻结基线 |
| 0.90 | 0 | 18448.853760 | 仍不激活 |
| 0.75 | 0.132835 | 18052.435040 | 正控激活 |
| 0.50 | 0.604094 | 11250.880675 | 强正控激活 |

预先固定的低价格正控产生稳定正储备，排除了储备变量失效、求解器总把 `R` 固定为零或结果提取错误等解释。它同时说明当前常规—应急相对价格是决定性因素；但不能据此把低于常规采购价格的应急采购当作现实校准。

### 3. 处置成本不是当前最坏情形的决定因素

在每个应急价格缩放下，将提前处置/到期损耗惩罚从 1 倍提高到 64 倍，目标和储备均不改变。基线中确实存在处置，但它出现在非绑定场景；当前 minimax 目标由高需求/缺货型最坏场景控制，因此低需求场景的处置损失没有改变最坏情形或第一阶段方案。

该结论只适用于本开发种子和预先固定网格，不是一般定理。

### 4. E5 加价变化来自缺货惩罚联动

当缺货惩罚保持基准值时，加价均值从 0.35 改为 0.15 或 0.55，目标变化均精确为 0，储备和应急采购仍为 0。按冻结规则让缺货惩罚随加价联动时，单种子目标分别变化 `-1899.5000074550` 和 `+1899.5000074550`。

因此，E5 的对应结果不能解释为纯应急价格效应；在 `R=0` 条件下，它是缺货惩罚联动校准效应。

## 真正原因判断

当前证据支持以下组合解释：

1. 常规采购确定可得、无采购上限，并且在冻结校准中单位价格低于应急采购；
2. 储备每增加一元，就减少一元可用于更便宜常规采购的预算；
3. 最坏情形由高需求/缺货成本主导，而不是低需求处置成本主导；
4. 因而，灾前常规采购在冻结 minimax 目标下压倒了保留预算灵活性的价值。

这是一项经济结构导致的边界最优解，不是数值错误，也不是 C&CG/SPW-C&CG 错误。

## 推荐论文路线

综合已完成正式结果与时间成本，建议采用“保留冻结模型、诚实报告零储备边界”的路线：

- 创新表述调整为：固定总预算下储备比例由模型内生决定，并给出在什么经济结构下退化为零储备的边界刻画；
- E4 用于展示固定储备的风险—收益权衡：平均成本和服务水平改善，但尾部风险没有一致改善；
- E5 与本诊断共同解释为什么冻结鲁棒目标选择零储备；
- SPW-C&CG 的算法创新与冷热目标一致性仍独立成立；
- 不宣称“正储备激活”或“内生储备经验上优于固定策略”。

如果论文必须以正储备激活为核心经验结论，应新开、冻结并复审一个扩展模型，优先考虑现实的常规采购容量、交货提前期或供应可靠性限制，并将缺货惩罚与应急加价解耦。不要仅把应急价格人为降到常规价格以下来制造正储备；那只能作为正控，不能构成可信论文证据。该扩展会改变科学模型并要求重新判断实验范围，不应混入当前冻结 Phase 6。
