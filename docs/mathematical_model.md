# 数学模型（阶段 1 初稿）

## 1. 时间顺序

在灾害不确定性揭示前，决策者确定整个计划期的常规采购到货计划 `y`，并在总预算中保留应急储备金 `R`。场景 `omega` 揭示需求、应急价格和应急供应后，按场景决定应急采购、库存消费、期末库存、缺货和过期。常规采购计划不可按场景改变；补救变量完全场景适应。

## 2. 集合与索引

- `k in K`：物资；第一版 `|K|=1`。
- `t in T={1,...,H}`：时期。
- `a in A_k={0,...,L_k-1}`：库龄；`a=0` 为最新，`a=L_k-1` 为最后可用库龄。
- `omega in Omega`：有限候选不确定场景。

## 3. 参数

- `B >= 0`：总预算。
- `c0[k,t] >= 0`：灾前承诺的常规采购单价。
- `d[omega,k,t] >= 0`：场景需求。
- `p[omega,k,t] >= 0`：场景应急采购单价。
- `u[omega,k,t] >= 0`：场景应急最大供应量。
- `L[k] >= 1`：保质期对应的可用库龄数。
- `C[t] >= 0`：期末仓储容量。
- `I0[k,a] >= 0`：计划期开始时的分库龄库存。
- `pi_s[k] >= 0`：单位缺货惩罚，使用统一货币量纲。
- `pi_w[k] > 0`：单位库存退出惩罚，同时用于提前处置和到期损耗。
- `gamma_q, gamma_s, gamma_w > 0`：经缩放后的无量纲权重，基础版通常取 1，并通过惩罚参数本身表达相对重要性。

## 4. 第一阶段变量

- `y[k,t] >= 0`：灾前确定、在时期 `t` 期初到货的常规采购量。
- `R >= 0`：应急储备金。
- `theta >= 0`：最坏场景补救成本上界。

常规采购承诺为

```math
C^0(y)=\sum_{k\in K}\sum_{t\in T} c^0_{kt}y_{kt}.
```

## 5. 第二阶段变量

对每个 `omega,k,t,a`：

- `q[omega,k,t] >= 0`：应急采购量。
- `b[omega,k,t,a] >= 0`：当期消费前可用的分库龄数量。
- `x[omega,k,t,a] >= 0`：从库龄 `a` 消费的数量。
- `I[omega,k,t,a] >= 0`：消费、过期处置后的期末分库龄库存；最后可用库龄的 `I` 固定为 0。
- `s[omega,k,t] >= 0`：缺货量。
- `w_exp[omega,k,t] >= 0`：最大库龄库存的到期损耗。
- `e[omega,k,t,a] >= 0`：非最大库龄库存的提前报废、捐赠、调出或其他
  现实处置量，仅对 `a<L[k]-1` 定义。
- `D[omega,k,t] = w_exp[omega,k,t] + sum_a e[omega,k,t,a]`：
  总库存退出量。

## 6. 库龄流与需求约束

### 6.1 最新库龄流入

```math
b_{\omega kt0}=y_{kt}+q_{\omega kt}+\mathbf{1}_{\{t=1\}}I^0_{k0}.
```

### 6.2 旧库龄流入

对 `a=1,...,L_k-1`：

```math
b_{\omega kta}=\mathbf{1}_{\{t=1\}}I^0_{ka}
+\mathbf{1}_{\{t>1\}}I_{\omega k,t-1,a-1}.
```

### 6.3 分库龄平衡与到期退出

对尚可结转的库龄 `a=0,...,L_k-2`：

```math
b_{\omega kta}=x_{\omega kta}+I_{\omega kta}+e_{\omega kta},
\qquad \forall \omega,k,t,a<L_k-1.
```

对最后可用库龄：

```math
b_{\omega kt,L_k-1}
=x_{\omega kt,L_k-1}+w^{exp}_{\omega kt},
```

并固定

```math
I_{\omega kt,L_k-1}=0.
```

这样，最后可用库龄的剩余量只记为当期浪费并立即退出系统，不会同时被计为期末库存。若 `L_k=1`，所有当期未使用库存均在期末过期。

### 6.4 需求满足

```math
\sum_{a\in A_k}x_{\omega kta}+s_{\omega kt}=d_{\omega kt},
\qquad \forall \omega,k,t.
```

### 6.5 仓储容量

```math
\sum_{k\in K}\sum_{a=0}^{L_k-2}I_{\omega kta}\le C_t,
\qquad \forall \omega,t.
```

阶段 2 统一采用“消费和过期处置后的期末库存容量”口径。该口径不包含已经计入 `w` 的到期物资，避免库存与浪费双重计量。模型暂不限制期初到货瞬间的临时占用；如实际仓库要求到货前检查容量，应在后续阶段增加消费前容量约束。

## 7. 应急市场与预算

### 7.1 场景供应上限

```math
0\le q_{\omega kt}\le u_{\omega kt},
\qquad \forall \omega,k,t.
```

### 7.2 场景应急采购预算

```math
\sum_{k\in K}\sum_{t\in T}p_{\omega kt}q_{\omega kt}\le R,
\qquad \forall \omega.
```

### 7.3 预算可识别性

若只使用 `C0(y)+R <= B`，而 `R` 不直接进入目标，预算存在剩余时 `R` 可能不唯一，导致储备比例不可识别。内生储备主模型默认采用

```math
C^0(y)+R=B.
```

其含义是：未承诺给常规采购的预算全部保留为可用应急资金，但实际应急支出仍可小于 `R`。如果政策允许资金完全不分配，则可增加 `U>=0`，令 `C0(y)+R+U=B`，并把最小化 `U` 作为末级词典序目标。

## 8. 场景补救成本与主目标

定义

```math
Q(y,R,\omega)=
\gamma_q\sum_{k,t}p_{\omega kt}q_{\omega kt}
+\gamma_s\sum_{k,t}\pi^s_k s_{\omega kt}
+\gamma_w\sum_{k,t}\pi^w_k
\left(w^{exp}_{\omega kt}+\sum_{a<L_k-1}e_{\omega kta}\right).
```

所有项先换算到同一货币量纲。缺货惩罚应高于采购与浪费成本，但使用相对单价倍率和敏感性分析，不使用未经缩放的极端大数。

两阶段鲁棒目标为

```math
\min_{y,R}\left\{C^0(y)+\max_{\omega\in\Omega}Q(y,R,\omega)\right\}.
```

`R` 是资金可用上限而不是已经发生的支出，因此不直接加入成本；真实灾后支出由 `p*q` 计入 `Q`。

## 9. 完整场景扩展式

对每个 `omega` 创建一组补救变量和第 6-7 节约束，求解

```math
\min\quad C^0(y)+\theta
```

满足

```math
C^0(y)+R=B,
```

```math
\theta\ge Q(y,R,\omega),\qquad \forall \omega\in\Omega,
```

以及所有场景补救约束。这是 `EndogenousReserveExtensiveModel`，用于小规模金标准。

## 10. 其他模型

### 10.1 DeterministicModel

构造均值场景

```math
\bar d_{kt}=|\Omega|^{-1}\sum_\omega d_{\omega kt},\quad
\bar p_{kt}=|\Omega|^{-1}\sum_\omega p_{\omega kt},\quad
\bar u_{kt}=|\Omega|^{-1}\sum_\omega u_{\omega kt},
```

只保留该场景并求解同一结构。它是规划基线，不代表样本外鲁棒性。

### 10.2 FixedReserveModel

给定 `rho in [0,1]`：

```math
R=\rho B,\qquad C^0(y)+R\le B.
```

实验比较时补救部分使用全部训练场景，以便只比较储备机制。常规采购额度未使用的部分不能自动转入应急资金，反映固定比例的刚性。

### 10.3 全部灾前采购模型

令 `R=0`，从应急预算约束立即得到所有 `q=0`，用于检验应急灵活性的价值。

## 11. FIFO 处理

基础连续 LP 不用 Big-M 或二进制变量强制 FIFO。若同一时期消费了较新库存而留下较老库存，可以在不改变当期需求满足的情况下交换同量消费：多消费旧库存、少消费新库存。该交换不增加采购或缺货成本，并在非负浪费成本、无库龄收益的假设下弱化未来过期风险。因此至少存在一个 FIFO 最优解。

由于 LP 退化，求解器不保证返回的每个最优解都严格 FIFO。阶段 2 只保证“至少存在一个 FIFO 最优解”，尚未执行第二级破平局。后续可在固定主目标最优值后增加

```math
\max\quad \sum_{\omega,k,t,a}a\,x_{\omega kta},
```

以优先消费较老库存。若业务要求所有可行解都严格执行 FIFO，则需要互补或二进制逻辑；该 MILP 扩展不属于第一版。

## 12. 不可行补救与 C&CG

缺货变量保证需求不足不会导致不可行，但受限主问题尚未见到低需求/低容量场景时，可能选择过大的 `y`，使该场景库存容量不可行。逐场景补救求解必须区分三种状态：最优、不可行、求解失败。

- 若发现不可行补救场景，当前第一阶段解的真实鲁棒上界视为 `+infinity`，优先把一个不可行场景及其完整补救约束加入主问题。
- 场景加入后，主问题会调整 `y`；不需要 Big-M 可行性罚项。
- 求解失败或超时不得当作不可行，必须记录并停止该次算法运行。

可选的“提前处置库存”变量能够保证完全补救，但会改变浪费定义；第一版先保留上述精确不可行场景处理。

## 13. 词典序接口

主实现使用缩放后的加权成本。可选词典序顺序为：

1. 最小化最坏场景总缺货；
2. 在一级最优值固定后，最小化过期浪费；
3. 在前两级固定后，最小化实际采购支出；
4. 最后最大化库龄加权消费以破除非 FIFO 平局。

每一级通过固定前一级最优值并重新求解实现，不依赖求解器专有多目标接口。

## 14. 提前处置与相对完全补救（2026-07-31 修订）

Phase 6 pilot 的 Gurobi IIS 证明：旧模型在“固定灾前采购、样本外低需求、
有限期末容量”组合下，尚未到期的剩余库存没有退出通道，可能使库龄流转与
仓储容量同时不可满足。为修复这一结构边界，对所有
\(a<L_k-1\) 增加

```math
e_{\omega kta}\ge 0,
```

表示尚未到期库存的提前报废、捐赠、跨区域调出或其他现实处置。最后库龄
仍只使用 \(w^{exp}_{\omega kt}\) 表示到期损耗。定义

```math
D_{\omega kt}
=w^{exp}_{\omega kt}+\sum_{a=0}^{L_k-2}e_{\omega kta}.
```

因此，`expired_waste`、`early_disposal` 和 `total_disposal` 分别对应
\(w^{exp}\)、\(e\) 和 \(D\)。兼容字段 `waste` 明确定义为
`total_disposal` 的别名，不再仅表示到期损耗。两类退出都沿用已有的
`waste_penalty[k]`，不存在免费丢弃，也不引入 Big-M。

相对完全补救可由构造法证明。对任意非负有限需求场景，以及任意满足
第一阶段预算约束的 \(y,R\)，令应急采购和消费为 0、缺货等于需求、
期末库存为 0；每期尚未到期的全部可用库存进入 \(e\)，最大库龄库存进入
\(w^{exp}\)。此时应急支出为 0，不超过 \(R\)，仓储使用量为 0，不超过
任意非负容量，所有库存和需求平衡均成立。因此第二阶段至少存在一个
可行解。`infeasible` 与求解器失败仍严格区分；若今后再次出现
`infeasible`，应作为模型或数据异常调查，不能删除场景或用 Big-M
伪造成本。
