# Phase 6 M2 双物资确认实验设计

## 目的与边界

单物资阈值细化已将自主储备激活边界定位在损失尺度 `(0.2, 0.3]`，并确认 `beta=1.1/1.3` 的 T03 可产生适度自主储备。本协议只设计双物资确认，用于检验同一应急储备池是否会根据两种异质物资的场景缺口进行跨物资动态分配。本设计不授权运行实验或正式扩展。

## 双物资异质性

使用冻结生成器前两个物资原型：物资1的需求倍率、价格倍率、保质期分别为 `1.0/1.0/6`；物资2为 `0.75/1.2/4`。为预注册供应脆弱性差异，两个物资分别使用确定性倍率 `0.8/1.2`：

$$
\alpha_{it\omega}=\operatorname{clip}\left(1-\ell_p v_i\Phi(Z^D_{it\omega}),0,1\right).
$$

其中 `C0` 显式令所有 $\alpha=1$；`C1` 使用 $\ell=0.2$；`T03` 使用 $\ell=0.3$。脆弱性倍率不产生新随机抽取。需求、应急价格、应急供应与场景顺序在同一 seed—beta 的三档之间严格共享。

## 冻结矩阵

- 独立档位为 `M2C2`，不得继承单物资 V1 的参考预算；
- 双物资理论期望参考预算为 $B_{ref}=2337.610924158743$，由两个物资逐期的常规价格乘理论期望需求求和；
- 两档实际预算分别为 `2571.372016574617` 与 `3038.894201406366`；仓储容量按两物资逐期理论需求之和的1.5倍重新计算；
- 5个全新确认种子：`2026081301–2026081305`；
- 预算：`beta=1.1,1.3`；
- 中断：`C0,C1,T03`；
- 总量：`5 × 2 × 3 = 30`；
- 每个配置只运行一次，种子是独立单位；仅作有限描述性机制确认。

## 为什么保留 C0

`C0`验证双物资结构本身不会制造虚假储备；`C1`是轻度中断对照；`T03`是已由单物资实验预注册的阈值附近处理。C0 不仅要求储备不激活，还必须在履约率逐元素等于1时，与关闭供应中断的同一双物资模型在鲁棒目标、容差最优储备区间和双向固定第一阶段逐场景补救评价上数值一致。只有 T03 相对 C0/C1 呈现更高且适度的激活，同时共享资金确实在两种物资间随场景变化，才能支持跨物资机制。

## 机器门槛

30/30必须最优且共同随机数全部通过。每个预算独立判断：C0必须0/5实质激活；T03至少3/5实质激活且至少3/5位于5%–50%适度区间；T03激活数必须严格高于C1。

跨物资指标固定使用完整扩展式识别的 $R_{min}^{opt}$ 端点所对应第一阶段方案，并在全部50个训练场景中独立精确补救。定义 $E_{i\omega}=\sum_t p^e_{it\omega}q^e_{it\omega}$、$E_\omega=\sum_iE_{i\omega}$；只在 $E_\omega>10^{-7}$ 时计算 $s_{1\omega}=E_{1\omega}/E_\omega$，并以 $\Delta s_1=\max s_{1\omega}-\min s_{1\omega}$ 衡量变化。至少3/5种子须满足：两种物资各自在至少一个场景有正应急支出、至少两个场景有正总应急支出且 $\Delta s_1\ge10^{-4}$。论文只可称“在所选 $R_{min}^{opt}$ 端点方案中观察到跨物资动态分配”，不得推广为所有最优补救方案均如此。

至少一个预算同时通过完整性、CRN、激活、适度储备及跨物资门槛，才允许另建正式扩展设计 PR。若仅一个预算通过，后续设计只能包含该预算且禁止讨论预算效应；只有两个预算均通过，才允许比较 `beta=1.1/1.3` 的预算调节作用。成本、服务水平、P95、CVaR和人工趋势均不得用于挑选预算。

## 后续流程

本设计 PR 通过后，另建独立冻结与安全 runner PR；runner 复审通过后才允许运行30组确认实验。任何阶段均不自动授权正式扩展或 M0 E3。
